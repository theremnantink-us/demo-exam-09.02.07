# Демо-экзамен 09.02.07 — универсальный шаблон ИС

Информационная система на **PHP + MySQL** (под XAMPP) для демонстрационного экзамена
по специальности **09.02.07 «Разработчик веб и мультимедийных приложений»**.

Закрывает все типовые модули задания: регистрация с валидацией, авторизация,
личный кабинет с историей заявок, форма заявки, панель администратора, адаптив,
мобильные макеты 390×844, ER-диаграмма. Тема меняется правкой одного файла `config.php`.

---

## 🚀 Запуск на ПК (Windows + XAMPP)

1. Скопируй папку проекта в `C:\xampp\htdocs\exam`.
2. В **XAMPP Control Panel** нажми **Start** у **Apache** и **MySQL**.
3. Открой в браузере: **http://localhost/exam/**

База данных и таблицы с тестовыми данными создаются **автоматически** при первом
открытии (это делает `db.php`). Импортировать ничего не нужно.

> Если порт 80 занят — в XAMPP поменяй Apache на порт 8080, тогда адрес `http://localhost:8080/exam/`.
> Если у MySQL есть пароль — впиши его в `config.php` → `DB_PASS`.

## 🔧 Адаптация под свою тему

Правишь **только `config.php`**: название системы, как зовётся сущность
(заявка/заказ/запись), список услуг (≥10 для базы), статусы. Везде в коде расставлены
комментарии-подсказки `🔧 ИЗМЕНИТЬ`. Подробно — в `README_подсказки.md`.

---

## 🗄️ База данных и отчёт

Папка **`sql/`** — отдельные файлы для phpMyAdmin (вкладка SQL, вставляй по порядку):

| Файл | Назначение |
|------|------------|
| `sql/01_create_database.sql` | создание базы |
| `sql/02_schema.sql` | структура 3 таблиц |
| `sql/03_data.sql` | тестовые данные (10+ строк) |
| `sql/04_report_queries.sql` | готовые SELECT-запросы для отчёта (скриншоты) |
| `sql/erwin_reverse.sql` | ASCII-DDL для импорта модели в **ERwin** |
| `database.sql` | всё-в-одном (структура + данные) для импорта целиком |

## 📁 Структура проекта

```
exam/
├─ config.php          🔧 настройки темы (правишь это)
├─ db.php              подключение + автосоздание БД
├─ helpers.php         валидация полей
├─ auth.php            сессии (клиент/админ)
├─ layout.php          общая шапка/подвал
├─ index.php login.php register.php logout.php
├─ cabinet.php order.php
├─ admin_login.php admin.php admin_logout.php
├─ assets/            style.css, app.js
├─ sql/               SQL-файлы для phpMyAdmin и ERwin

├─ docs/              ER-диаграмма (md, svg, png)
├─ database.sql       полный дамп БД
└─ README_подсказки.md  подробные подсказки
```
