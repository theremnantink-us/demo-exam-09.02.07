# 🟢 Шпаргалка по проекту (демо-экзамен 09.02.07, издание 2026)

Универсальный шаблон ИС (главная → регистрация → заявки → отзывы → админка) с
**подсистемой безопасности**. Тема на экзамене другая — структура одинаковая.

---

## 1. Запуск (XAMPP, Windows)
1. Скопируй `exam` в `C:\xampp\htdocs\`.
2. Запусти **Apache** и **MySQL** в XAMPP.
3. Открой `http://localhost/exam/` — БД и тестовые данные создадутся сами.
4. Дали готовый файл БД? phpMyAdmin → Импорт → `database.sql`.

**Доступы:** пользователь `ivanov1` / `Parol12345`; админ `Admin` / `KorokNET`.

---

## 2. Переделать под свою тему

### Внешность и наполнение прописаны прямо в файлах (с комментариями)
- **Цвета и шрифты** — `assets/style.css`, блок `:root` вверху.
- **Название и контакты** — `layout.php`.
- **Тексты главной, hero, слайдер, преимущества** — `index.php`.
- **Курсы/статусы/оплата** — `db.php` (сид) и страницы `order.php`, `admin.php`, `cabinet.php`.
- **Доступ админа** — `admin_login.php` (логин/пароль прямо в коде).

> На экзамене нет интернета: ссылка Google Fonts в `layout.php` может не загрузиться —
> тогда останется системный шрифт (сайт не сломается). Можно скачать .woff2 и подключить
> локально через `@font-face`. Картинки-заглушки в `assets/img/` замени на фото из задания.

### Сброс базы после правок данных
phpMyAdmin → база `exam_db` → Operations → Drop, затем обнови страницу — пересоберётся.

## 4. Подсистема безопасности — показать эксперту (это 8 баллов!)
Открой `security.php` и `docs/БЕЗОПАСНОСТЬ.md`. Кратко защищено от:
SQL-инъекций (подготовленные запросы), XSS (экранирование + CSP), CSRF (токены в формах),
брутфорса/DDoS (rate limit), кражи сессии, открытых паролей (хеширование) + HTTP-заголовки.

---

## 5. Частые проблемы
- **Ошибка подключения к MySQL** — не запущен MySQL, либо пароль в `config.php` неверный.
- **Текст файла вместо страницы / «лишний вывод»** — где-то в PHP-комментарии попался
  символ `?>` (он закрывает PHP). Убери его из комментария.
- **Крякозябры** — таблицы и файлы должны быть в UTF-8 (у нас так).
- **Слайдер/маски не работают** — проверь, что подключён `assets/app.js` (он в подвале).
