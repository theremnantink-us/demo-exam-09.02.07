# 🟢 Шпаргалка по проекту (демо-экзамен 09.02.07)

Это **универсальный шаблон** информационной системы (регистрация → заявки → админка).
Тема на экзамене будет другая, но структура заданий одинаковая. Ниже — что и где менять.

---

## 1. Как запустить (XAMPP, Windows)

1. Скопируй папку `exam` в `C:\xampp\htdocs\`.
2. Запусти в XAMPP **Apache** и **MySQL**.
3. Открой в браузере: `http://localhost/exam/`
   База данных и тестовые данные создадутся **автоматически** при первом заходе.
4. Если дают готовый файл БД (Модуль 1/2): phpMyAdmin → Импорт → выбери `database.sql`.

**Доступы для проверки:**
- Пользователь: логин `ivanov`, пароль `123456` (или зарегистрируй нового).
- Админка: `http://localhost/exam/admin_login.php`, логин `adminka`, пароль `password`.

## 2. Переделать под свою тему за ~20 минут

### Шаг 1. `config.php` — 90% всех изменений тут
- `name` — название системы из задания.
- `entity_label` / `entity_label_gen` / `entity_label_plural` — как называется заявка
  (заявка / заказ / запись / бронь / обращение).
- `services[]` — **главное**: список услуг/товаров/категорий из твоего задания.
  Сделай **10+ пунктов** (требование: 10+ строк в БД).
- `payment_types[]`, `statuses[]` — если в задании другие.

### Шаг 2. Если нужны ДРУГИЕ поля (например «количество», «комментарий»)
- Добавь столбец в таблицу `orders` в **двух** местах: `db.php` (функция `init_schema`)
  и `database.sql`.
- Добавь поле `<input>` в форму `order.php` и в `INSERT` там же.
- Покажи столбец в таблицах `cabinet.php` и `admin.php`.
Везде стоят пометки `🔧` — ищи их (Ctrl+F по `🔧`).

### Шаг 3. Сбросить базу после смены config
Если уже заходил и таблицы заполнились старыми данными — в phpMyAdmin удали базу
`exam_db` (Operations → Drop) и обнови страницу: она пересоберётся из нового config.

## 4. Частые проблемы

- **Белый экран / ошибка подключения** — не запущен MySQL в XAMPP, либо в `config.php`
  неверный пароль (XAMPP: `root` / пусто).
- **«Логин уже занят»** при регистрации — он реально есть в БД, возьми другой.
- **Кириллица в виде «крякозябр»** — проверь, что таблицы в `utf8mb4` (у нас так),
  и что файлы сохранены в UTF-8.
- **Не работает маска телефона** — проверь, что подключён `assets/app.js` (он в подвале).

## 5. Порядок работы на экзамене (рекомендация)
1. Прочитай задание, выпиши: название, список услуг, поля заявки, статусы.
2. Открой `config.php`, внеси всё из пункта 1.
3. Проверь, что система запускается и регистрация работает.
4. Если есть лишние/недостающие поля — правь по Шагу 2.
5. Сделай ER-диаграмму (`docs/ER.md`) и мобильные макеты (`mobile/`).
6. Проверь чек-лист из таблицы выше — каждый пункт должен работать.
