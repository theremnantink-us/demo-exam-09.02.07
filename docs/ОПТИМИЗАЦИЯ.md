# Оптимизация веб-приложения

> Модули 2 и 3 требуют «оптимизировать изображения» и «не забывать про качество
> и технологичность». Ниже — что сделано и как показать эксперту.

## 1. Ленивая загрузка изображений (lazy loading)
Картинки ниже первого экрана грузятся только при прокрутке — страница открывается
быстрее. Реализовано через `loading="lazy"` в хелпере `media_picture()` (`helpers.php`).
- Hero (главное фото) грузится **сразу** (`loading="eager"`, `fetchpriority="high"`) —
  это LCP-элемент, его лениво грузить нельзя.
- Первый слайд слайдера — сразу, остальные 3 — лениво.

## 2. Формат WebP (меньше вес на 25–35%)
`media_picture()` выводит `<picture>` с источником `.webp` и фолбэком на оригинал:
```html
<picture>
  <source srcset="assets/img/hero.webp" type="image/webp">
  <img src="assets/img/hero.jpg" loading="lazy" decoding="async" width="640" height="440">
</picture>
```
Браузер сам берёт WebP, если умеет, иначе — оригинал. Старые браузеры не ломаются.

**Как получить WebP** (после того, как положил настоящие фото в `assets/img/`):
- из браузера: `http://localhost/exam/tools/convert-webp.php`
- или из консоли: `php tools/convert-webp.php`

Скрипт `tools/convert-webp.php` сам пройдёт по `assets/img/` и создаст `.webp`.

## 3. Защита от «прыжков» вёрстки (CLS)
У изображений заданы `width`/`height`, у слайдера — `aspect-ratio`. Браузер заранее
резервирует место — контент не «скачет» при загрузке.

## 4. `decoding="async"`
Декодирование картинок не блокирует отрисовку страницы.

## 5. Сжатие и кэширование (.htaccess)
- **Gzip** (`mod_deflate`) — HTML/CSS/JS/SVG отдаются сжатыми (меньше трафик).
- **Кэш в браузере** (`mod_expires`) — статика (картинки/стили/скрипты/шрифты) кэшируется,
  при повторном заходе не качается заново.

## 6. Прочее
- Скрипт `app.js` подключён в конце страницы (не блокирует загрузку).
- Иконки/графика главного экрана — SVG (векторные, минимальный вес, чёткие на любом экране).
- Слайдер ставится на паузу при наведении и не тратит ресурсы вхолостую.

## Как показать эксперту
1. Открой код страницы (Ctrl+U) — у картинок виден `loading="lazy"` и тег `<picture>`.
2. Открой `helpers.php` → функция `media_picture()`.
3. Запусти `tools/convert-webp.php` — покажет создание `.webp`.
4. В DevTools (F12) → вкладка Network → видно, что нижние картинки грузятся при скролле.
